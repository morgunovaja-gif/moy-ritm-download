# Мой ритм — скачать для Android

Спокойное приложение для заботы о себе и доме: вода с мягкими напоминаниями, шаги с часов, трекеры привычек, дела по дому с периодичностью, дневник еды и настроения и советы по продуктовой корзине из «Двух карманов».

## ⬇️ [Скачать приложение (APK)](https://github.com/morgunovaja-gif/moy-ritm-download/releases/latest/download/moy-ritm.apk)

## Как установить

1. Нажмите на ссылку выше с телефона — начнётся скачивание файла `moy-ritm.apk`.
2. Откройте скачанный файл.
3. Если телефон спросит, разрешить ли установку из этого источника, — разрешите.
4. Если Google Play Защита предупредит о неизвестном приложении, нажмите «Всё равно установить»: так бывает со всеми приложениями не из Play Market.

## Шаги с часов и цикл

Данные приходят через Health Connect (на телефоне называется «Здоровье и спорт»). В нём разрешите Honor Здоровье, Flo и другим приложениям записывать данные, а «Моему ритму» — читать.

## Обновления

Приложение само подскажет, когда выйдет новая версия. Обновление ставится поверх старой — данные сохраняются.
